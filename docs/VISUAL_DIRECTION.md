# Visual Direction

Working direction from the first brand pass:

## Signal autonome

A compact monochrome symbol, built around a visible invariant: decoy, signal, containment. Avoid generic shields and cute bee mascots.

## Rythme typographique propriétaire

A calm technical wordmark with one local anomaly. The name should feel clinical and undercover, not malware-themed.

## Champ vivant gouverné

A governed grid that can show agent messages, risk signals, quarantine, and audit trails as a structured field.

## Diagram principle

```text
agents -> recruitment attempt -> Honey Agent -> risk engine -> policy engine -> quarantine -> audit ledger -> human review
```

Tone: defensive, clinical, auditable, research-grade.
